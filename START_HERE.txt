WHAT CHANGED IN v20
- RSVP is now invite-only instead of an open guest form.
- Guests search using an invited full name + the matching email OR phone on their invitation.
- Only the named guests on that invitation are shown.
- Plus-ones only appear when Admin explicitly allows them.
- Guests answer Yes/No person-by-person.
- One household contact email/phone is maintained.
- Guests can update their mailing address and leave a message.
- RSVP responses can be reopened/edited later with the same lookup info.
- The RSVP page includes a private Guest List Admin area using the same tournament Admin code.
- RSVP body text/buttons remain large and phone-friendly.

B) RSVP SUPABASE SETUP
============================================================
For the new invite-only RSVP system, open Supabase -> SQL Editor and run:

SUPABASE_SETUP/04_WEDDING_RSVP_INVITE_ONLY_v20.sql

This is safe to run in the same Supabase project as the volleyball tournament.
It creates NEW wedding RSVP tables/functions and does not reset tournament data.

You do NOT need to rerun the tournament SQL files just to add RSVP v20 if the tournament is already working.

After running the RSVP SQL:
1. Upload the new rsvp.html.
2. Open RSVP on the live website.
3. The banner should say "RSVP system connected ♡".
4. Scroll to the bottom and choose "Guest List Admin".
5. Enter the same Admin code used for the tournament.
6. Add your first test invitation/household.
7. Exit Admin and test "Find My Invitation" using that invited person's name + stored email/phone.

============================================================
C) GUEST LIST LOGIC
============================================================
Each invitation contains:
- Household / invitation name
- Primary contact name
- Email and/or phone used for lookup
- Mailing address
- Named invited guests
- Number of allowed plus-one spots

PUBLIC GUESTS CANNOT BROWSE THE GUEST LIST.
They only receive an invitation after matching BOTH:
1. an exact invited name, and
2. the email or phone stored for that invitation.

Plus-one names are entered only if that plus-one is attending.
